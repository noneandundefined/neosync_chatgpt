# NeoSync Web

React + TypeScript + Vite клиент NeoSync.

```text
apps/
├── components/
├── constants/
├── context/
├── hooks/
├── interface/
├── locale/
├── pages/
├── rest/
├── router/
├── styles/
└── utils/
```

```bash
pnpm install
pnpm dev
pnpm build
```

Frontend — самостоятельное приложение в `apps/web`, а не resource-файл backend/client проекта.
